# Provenance and credits

Team: POLIBU. Game design, original code and code-generated assets developed with Codex (GPT-6). No imported mesh files or literal vertex-array models.

## Geometry and review

`references/candidates/` contains A/B/C alternatives for ten prop families with five-view renders. A started from the scene concept/form brief; B and C were independently constructed after inspecting Atlas object references. `references/selections.json` records the visual selections. `assets/` contains the final eleven modules, including a separate harlequin rotating wall. The selected creature and recorder received rear-surface detail repairs after verification. The final asset report is `assets/_verify/report.json`.

Floor, ceiling, light fittings, furniture supports, signs and the shutter are original procedural Three.js scene geometry in `src/world.js`; they did not each receive a separate three-candidate comparison. This project does not claim an independent blind critic score.

## Images

Atlas project: **Fright House — jam art and sound**, ID `d29db3e5-92f2-4d87-ac41-3d08827a10ac`, in Polina Bulatova’s 404 Game Jam Workspace. Ten object references were generated via Atlas with Gemini 3.1 Flash Lite Image; their file IDs are in `references/atlas/assets.json`. The early panel pilot showed the wrong object and was replaced. Reference images are not included in the runtime build.

`references/funhouse-concept.png` is an initial OpenAI image-generation concept made outside Atlas, retained only as a declared development reference. Its brief was an abandoned 1987 painted-timber funhouse, distorted carnival faces, amber lighting and a teal maintenance door. No external bitmap textures ship. Paint, wood marks, lettering and UI graphics are generated by our code.
